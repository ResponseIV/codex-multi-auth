# v2.17.2

Version resync release: no functional changes over what was prepared as
[v2.17.1](v2.17.1.md). The 2.17.1 version was prepared but never published —
npm, the git tag, and the GitHub release all went straight to 2.17.2, which
already carries every fix listed below. The changelog and release-notes
filenames are re-aligned so both versions keep their own records.

For the substantive changes, see the [v2.17.1 notes](v2.17.1.md). In short:
automatic subscription priming now keys quota observations by credential
record and selected workspace, concurrent quota cache writes merge instead of
overwriting each other, pending rotated credentials keep their `recordId`, and
app-bind cleanup works on non-English POSIX systems.

## Fixes

- Carries the same fixes as v2.17.1: per-workspace subscription priming quota
  keys, merge-based quota cache writes, `recordId` on pending rotated
  credentials, and `LC_ALL=C` app-bind process cleanup on non-English POSIX
  locales ([#706](https://github.com/ndycode/codex-multi-auth/pull/706),
  [`fc37c3ec`](https://github.com/ndycode/codex-multi-auth/commit/fc37c3ec)).
- Release hygiene: the 2.17.1 release notes and changelog entry were renamed
  in place during 2.17.2 prep instead of being kept as their own entry; both
  are restored, and the README/docs-portal release links point at the real
  current stable again.
